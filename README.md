# DeportSccy
- Descripción:Creamos una página web sobre el deportivo tepalcates esto con el fin de que la comunidad conozca sobre los eventos, avisos, horarios, ubicación, actividades que se realizan y los beneficios que aporta al prácticar un deporte para que tanto niños, jovenes, adultos y adultos mayores cuiden su salud y se distraigan de cualquier adicción.
- Problema que resuelve:Ahora las personas podrán revisar la informacion sobre las actividades, horarios, eventos, avisos, ubicación y beneficios para su salud.
- Funcionalidades principales:Inicio y registro de sesión, información sobre el deportivo Tepalcates, ubicación y informacion sobre otros deportivo.

- Tegnologias que podrían utilizarse:Computadora y dispositivos moviles.
